# eBay 簡易利益計算

[e-Shikumi-Labo の eBay簡易利益計算シート](https://e-shikumi-labo.com/tool-app/20170227_benecalc_r3b.html) と同じ計算ができる、オフライン利用可能なモダン版ツールです。

## 使い方

`index.html` をブラウザで開くか、ローカルサーバーで起動します。

```bash
python3 -m http.server 8765
# http://localhost:8765
```

## 計算式

元ツール (`20170227_benecalc_r3`) と同じです。

- **想定利益** = 出品価格 × (1 − 手数料%) × レート − 仕入れ価格 − 送料
- **利益率** = 想定利益 ÷ (出品価格 × レート) × 100
- **損益分岐** = (仕入れ価格 + 送料) ÷ ((1 − 手数料%) × レート)

## 入力項目

| 項目 | 単位 | 説明 |
|------|------|------|
| 出品価格 | USD | eBay の販売予定価格 |
| レート | 円/ドル | 着金時の実効レート（引き出し時のスプレッドを考慮） |
| 仕入れ価格 | 円 | 商品の仕入れ原価 |
| 手数料 | % | FVF・国際手数料・為替コストなどの合算目安 |
| 送料 | 円 | Free Shipping 時に負担する実送料 |
